# Meus Projetos em PHP e Python

Bem-vindo(a) ao meu repositório de projetos! Aqui você encontrará uma coleção de scripts, ferramentas e aplicações desenvolvidas em **PHP** e **Python**. 

O objetivo deste espaço é compartilhar soluções práticas, experimentar novas tecnologias e manter um portfólio acessível do meu trabalho de desenvolvimento.

---

## 🛠️ Tecnologias e Linguagens

- **Python:** Scripts de automação, análise de dados (Pandas, OpenCV), aplicações web (Streamlit, Flask/FastAPI) e ferramentas de utilidade geral.
- **PHP:** Sistemas web, APIs, integrações, manipulação de banco de dados e aplicações do lado do servidor.
- **Outras:** HTML, CSS, JavaScript (dependendo do projeto), bancos de dados (MySQL, SQLite), entre outras ferramentas.
